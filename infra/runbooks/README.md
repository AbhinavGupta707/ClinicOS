# Runbooks

Operational runbooks for local setup, deploys, backups, restore drills, provider outages, and pilot support.

- `local-development.md` - local service stack, env setup, ports, and app command activation notes.
- `backup-restore-drill.md` - CP9 synthetic restore dry-run, guarded local restore smoke, and evidence checklist.
- `provider-health-alerting.md` - provider-health status semantics, alert thresholds, and triage flow.
- `official-provider-activation.md` - CP15 Meta/Razorpay registration, rotation, callback verification, reconciliation, rollback, and evidence controls.
- `disaster-recovery.md` - `ap-south-1` primary / `ap-south-2` DR posture and failover evidence notes.
- `pilot-support-admin.md` - CP10 pilot support intake, escalation, degraded-mode, and provider no-key handling.
